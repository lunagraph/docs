## Use the chat panel

The chat panel runs Claude Code from your terminal with your own subscription. Your installed skills and MCP connections are available in the chat, so the agent works the same way it does in your terminal.

If you haven't set it up yet, follow [Install Claude Code](/install-claude-code).

## Use Lunagraph's MCP

Prefer a different coding tool? Connect it to Lunagraph's MCP instead. Your agent can design on the canvas while the Lunagraph desktop app is open. See [Connect MCP](/guides/connect-mcp) for setup steps.
