## Overview

Build behavior yourself or ask the AI to build it. You can navigate between screens, edit text, or create more complex interactions. Because the prototype uses real components, it behaves like the product you built. A text editor is a working text editor. A game is a playable game.

Anyone with the link can try the prototype in a browser. You can update it at any time without changing the link, so recipients always see the latest version.

## What is a prototype?

A prototype is a functional version of your design. It can include simple navigation, a working text editor, a clickable game, or anything in between.

Features that need live infrastructure have limits. Real user accounts, server-side data storage, and email delivery need a backend. Everything that runs in the browser works when you test the prototype and when someone opens the shared link.

## Create and share a prototype

1. **Design the screens.** Build the screens on the canvas with your existing components and design system. Lay out the flow that you want people to follow.

2. **Build the behavior.** Add interactions yourself, or press **Cmd + L** to reference your designs in the chat and describe the behavior you want.

3. **Try the prototype.** Click through the result on the canvas. You can use **Edit component** to refine any part of it, then ask the AI for further changes.

4. **Share the link.** Click the play button in the top-right corner to get a shareable link. Anyone with the link can open the prototype and interact with it in a browser.
